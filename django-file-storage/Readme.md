Django File Storage Application
Overview

This project is a Django File Storage Application developed as part of CSE 310 Module 3.
The application allows users to:
Upload files
View uploaded files
Download files
Delete files

The project was first developed and tested locally using Django's development server and was later deployed online using Render so that it can be accessed from anywhere.
Features
File upload functionality
View uploaded files in the browser
Download files
Delete files
Clean and responsive user interface
Django-based backend

Installation
Clone the repository.
Navigate into the project folder.
Create and activate a virtual environment.
Install dependencies:
pip install -r requirements.txt
Run database migrations:
python manage.py migrate
Start the development server:
python manage.py runserver

Open:
http://127.0.0.1:8000/
